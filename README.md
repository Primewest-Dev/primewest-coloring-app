# EmberPost Coloring App (prototype)

Offline-capable web app (PWA): Color by Number, Free Color and a story/unlock journey for three EmberPost chapters.

Open: https://primewest-dev.github.io/primewest-coloring-app/

Features: Line Lock (soft edge resistance), deep zoom up to 8x with crisp vector lines, color helper and ideas,
palette switcher (book + themed palettes + shiny pencil sets), chrome/glow/pulse pencils, 3D Pop, story cutscenes.

Purchases are **demo only**: no payment is taken. Premium products (pencils, palettes, effects3d) each come with
free samples. Payment/licensing hooks live in `premium-config.js`. Codes in that file are public; real licensing needs a server.
